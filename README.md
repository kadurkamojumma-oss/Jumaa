شرح الكود

أول شي عرفنا المخزن
عرفت struct اسمه CB فيه مصفوفة حجمها SIZE ومؤشرين head و tail وعداد count. الـ head للقراءة والـ tail للكتابة والـ count بعدد العناصر الموجودة.

دالة init
هي بتصفر كل القيم، بتخلي head و tail و count أصفار، يعني بكون المخزن فاضي وجاهز.

دالة full و empty
دالتين بسيطات، full ترجع 1 إذا count صار يساوي SIZE، و empty ترجع 1 إذا count صار صفر.

دالة write
أول شي بتتأكد إذا المخزن مليان، إذا مليان بتطبع Overflow وبتطلع
 إذا مو مليان بتحط الحرف في tail وبعدين بتزود tail بمقدار 1، وهون لما tail يوصل لآخر المصفوفة، % SIZE بتخليه يرجع للصفر (يلف) وبالآخر بتزيد count
يعني لو SIZE=5 و tail صار 4، المرة الجاية بيرجع 0

دالة read
نفس الفكرة بس بالعكس
 بتتأكد إذا فاضي إذا فاضي بتطبع Underflow إذا فيه عناصر بتاخذ الحرف من مكان head وبتزود head ب 1 مع اللفة وبتنقص count وترجع الحرف

دالة main
بتعرف المخزن وتستدعي init
بتسأل عم اسم المستخدم
بتدمج الاسم مع "CE-ESY" باستخدام strcpy و strcat
بتمرر على كل حرف بالاسم الكامل وتكتبه بالمخزن عن طريق write
إذا المخزن حجمه أصغر من عدد الأحرف رح تطبع Overflow وما تكمل كتابة
بعدين بتقرأ من المخزن حرف حرف وتطبعه
بالأخير تتأكد إنه فاضي

حالات الـ Overflow و Underflow
 Overflow: لما نحاول نضيف والمخزن مليان
Underflow: لما نحاول نقرأ والمخزن فاضي
